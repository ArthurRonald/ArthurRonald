## Projetos em destaque

### [Sistema de Treinos de Corrida](https://github.com/ArthurRonald/Sistema-para-montagem-de-treinos-de-corrida)
Aplicação web que gera planos de treino personalizados por objetivo (5K a maratona) e nível, com exportação de relatórios em PDF. Usa a **API do Gemini** para ajustar as recomendações a partir de check-ins diários de feedback do usuário.
**Stack:** Python · Streamlit · Gemini API

### [Árvore Genealógica em C](https://github.com/ArthurRonald/ArvoreGenealogica)
Estrutura de dados em árvore para modelar relações familiares e navegar pela hierarquia entre membros, usando `structs`, ponteiros e `malloc`. Projeto da disciplina de Linguagem de Programação 2, feito em dupla.
**Stack:** C · Estruturas de dados
